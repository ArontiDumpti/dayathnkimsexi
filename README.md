¿Quieres ser mi novia?

Al entrar, **Sí** y **No** están juntos. El primer clic en **No** lo suelta: a partir de ahí cambia de lugar y suelta un animalito que cruza la página, hasta 28. **Sí** muestra «Tiempo límite para llamarme» y una cuenta atrás de 5 minutos; la bomba crece y, al llegar a cero, llena la página de negro. El fondo lleva la marca de agua Hunti en letra de grafiti.

```bash
php -S 127.0.0.1:8643 -t .
```

Abre `http://127.0.0.1:8643`.
